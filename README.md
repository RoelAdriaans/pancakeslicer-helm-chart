# PancakeSlicer Helm Chart

A Helm chart for deploying [PancakeSlicer](https://github.com/ZimengXiong/PancakeSlicer), a web UI, service and slicing engine in one container.

The chart lives in [`charts/pancakeslicer`](charts/pancakeslicer); see its [README](charts/pancakeslicer/README.md) for configuration details.

## Issues

This repository only contains the Helm chart. Issues with the PancakeSlicer application itself should be reported to the upstream project: <https://github.com/ZimengXiong/PancakeSlicer/issues>.

Only open an issue here for problems with the chart.
